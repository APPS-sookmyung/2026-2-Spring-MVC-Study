## 📝 진행 방식

매주 정해진 강의를 각자 수강하고 학습 내용을 정리합니다.

각 스터디원은 해당 주차에 다음 내용을 진행합니다.

- 강의 수강
- 실습 코드 작성
- 학습 내용 정리
- 본인 폴더에 Commit
- 해당 주차 학습 내용을 Pull Request로 제출

해당 주차 발표자는 회의 전까지 질문을 준비합니다.
질문은 단순 내용 확인보다는 실제로 생각해볼 수 있는 질문을 권장합니다.

예시:

> "필터와 인터셉터의 차이는?"

다음과 같은 질문도 환영합니다.

- CS 면접에서 나올 법한 질문
- 강의 내용을 응용한 질문
- 본인의 관심 분야와 학습 내용을 연결한 질문

질문의 목적은 단순 암기보다 **학습한 내용을 오래 기억하고 서로 이야기해보는 것**입니다.
